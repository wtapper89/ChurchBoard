# ChurchBoard contributors

Thank you to everyone who has contributed code, testing, documentation, design feedback, and production experience to ChurchBoard.

- [William Tapper (@wtapper89)](https://github.com/wtapper89) — project creator and maintainer.
- [Caleb Hines (@WorshipWarehouse)](https://github.com/WorshipWarehouse) — Open Sound Meter integration and reporting, Restream OAuth monitoring, OBS Studio monitoring, Planning Center scheduled-person consolidation, complete order-of-service display modes, Sennheiser EW-DX and Shure SLX-D monitoring, ProPresenter playlist control and timers, ShowXpress/TheLightingController support, dashboard lifecycle controls, and responsive fullscreen improvements.
- [Justin Beale (@jbeale)](https://github.com/jbeale) — creator of the MIT-licensed ProdMesh Remote RTA and its read-only network API used by ChurchBoard's RTA module.

- [Zach Green and White Oak Media](https://github.com/whiteoakmedia/prodeck) — MIT-licensed ProDeck console protocol maps, MIDI commands, and SQ fader taper adapted for ChurchBoard.
- [Slide-Desk](https://github.com/gavinpep98/Slide-Desk) — behavioral reference for ProPresenter polling and playlist handling.
- [Karl Swanson and Micboard](https://micboard.io/) — inspiration for ChurchBoard’s microphone monitoring and level display.

Commit authorship is retained in the Git history. Contributions remain available under the repository's [MIT License](LICENSE).
