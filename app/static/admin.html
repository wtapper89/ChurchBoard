General
Web server

Restart ChurchBoard after saving. The volunteer port opens only sign-in, checklists, resources, and producer tools—not dashboards or setup. Port 80 may require administrator privileges; use 8080 or a reverse proxy when needed. HTTPS is required for mobile intercom microphone access.

Planning Center

Test the connection to choose which service types ChurchBoard may activate.

ProPresenter

Slide triggering is enabled separately on each ProPresenter Playlist widget in the board editor.

Services LIVE automation

Planning Center-synced ProPresenter items match by their playlist item and position first, including non-song items such as Message. Strong title matches can also select non-song items when no synced link is available.

Restream

In your Restream app, add as a Redirect URI and select the scopes you require. ChurchBoard keeps the secret and OAuth tokens only on this computer.

OBS Studio

In OBS, open Tools → WebSocket Server Settings, enable the server, and enter the same port and password here. A preview image URL is optional; OBS status monitoring works without it.

NDI® video
  1. Download the official NDI SDK directly and choose your operating system.
  2. Run its installer and keep the default location. ChurchBoard automatically checks the standard Windows, macOS, and Linux SDK/runtime folders.
  3. Enable NDI above, save, and select Save & find NDI sources. Only paste a path when you installed the SDK somewhere custom; the SDK’s top-level folder is accepted.

NDI Tools is not required. If the runtime is found but no source appears, enable NDI output in the sending application and confirm both computers are on the same multicast-enabled network. Official SDK instructions. NDI® is a registered trademark of Vizrt NDI AB.

Producer intercom
ChurchBoard starts and manages the intercom server automatically.

There is no cloud account, server URL, API key, or secret to enter. ChurchBoard hosts the LiveKit-based audio engine on this computer and uses the same HTTP or HTTPS address as the Producer workspace. Mobile browsers still require HTTPS before they allow AirPods or another microphone.

Wireless microphones

Add each receiver channel, select its receiver family, and assign its scheduled Planning Center position. Shure receivers use TCP port 2202; SLX-D requires Controller Access to be allowed in Advanced Settings. Sennheiser uses legacy SSC over UDP port 45.

Open Sound Meter

In Open Sound Meter, enable the Wi‑Fi icon’s Remote API Server. ChurchBoard listens for its UDP multicast level packets at 239.255.42.42:49007. The two computers must be on the same multicast-enabled network segment.
